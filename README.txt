JAWARIYA JEWELLERS — FINAL PREMIUM RINGS CATALOGUE

Main file: rings.html

This version is a single self-contained HTML file. All 104 product images and records are embedded in the file; no products.js or external image files are required.

Image handling:
- The 50 specification-bearing designs use crops of the main product-photo panel from the supplied PDF, excluding the supplier's navigation, thumbnail, product title and specification panels.
- The 54 standalone designs use the central product-photo area from the source PDF pages.
- The main grid displays only the ring photograph and its Jawariya serial number.

Catalogue behaviour:
- Tap any card to open its details within the same HTML file.
- Search by serial number.
- For the 50 designs with specification panels, available gold weight, diamond weight and diamond count are shown once, and the purity selector offers 9, 18, 20 and 22 karat.
- For the 54 designs without source specifications, purity is shown as 22 karat hallmark and the assigned weight is an estimate between 1.3 g and 3.0 g. The estimate warning is displayed.
- WhatsApp enquiry button opens a message to JAWARIYA JEWELLERS.

Validation performed:
- 104 distinct product serial numbers; no duplicates.
- 104 embedded JPEG images decoded successfully.
- 50 specification-bearing designs and 54 without specification panels.
- All 54 estimated weights are within 1.3–3.0 g and use the requested 22 karat hallmark label.
- Embedded JavaScript passed Node syntax validation.

Important:
Estimated weights are not measured product facts. Confirm the actual weight and hallmark before sale.
