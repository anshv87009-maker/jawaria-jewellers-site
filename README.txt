JAWARIYA JEWELLERS — PREMIUM, SELF-CONTAINED RINGS CATALOGUE

FILES
- rings.html: the entire catalogue in one HTML file. Product images and product records are embedded; no products.js or external assets are needed.

IMAGE EXTRACTION
- The 50 specification-page images were cropped to the main product photograph region, excluding the supplier webpage interface, thumbnails, product-code text, and specification panels.
- The 54 no-specification designs were cropped from their standalone photo panels.
- The main menu shows only each extracted ring image and its JAWARIYA serial number.

CATALOGUE CONTENTS
- 104 distinct designs from the 105-page PDF. Page 2 is a continuation/alternate view of the ring on page 1, not a separate design.
- 50 designs with source specification panels.
- 54 designs without specification panels. These show 22 karat hallmark and a 1.3–3.0 g estimated weight, clearly identified as estimated.
- Serial numbers run JW-RNG-0001 to JW-RNG-0104 in source PDF order, excluding page 2 duplicate/continuation.
- Search by serial number; tap a ring to open its details; use WhatsApp enquiry.

VALIDATION PERFORMED
- 104 unique serial numbers.
- All 104 embedded JPEG images decoded successfully.
- All 54 estimated weights are within 1.3–3.0 g and use the requested 22 karat hallmark label.
- Embedded JavaScript passed syntax validation.
- No external JavaScript, image URLs, fonts, or libraries are required.

IMPORTANT
Estimated weights are not measured facts and must be confirmed before sale. Source specifications are shown only when available in the source data; please verify OCR-read values before quoting customers.

PREVIEW
Open rings.html directly on a phone or computer. To publish, upload this file to the repository root as rings.html and connect the website's Ladies' Rings category link to it. This package does not modify the live GitHub website automatically.
